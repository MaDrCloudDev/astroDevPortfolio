# [astroDevPortfolio](https://astrodevportfolio.MaDr.io/)

The second, updated version of a modern visual portfolio I built with Astro, Astro components, and Tailwind. Originally built in Next.js - the performance of the final product wasn't great, so I migrated it all over to Astro. Eventually I was using a combination of React and Svelte components, and I migrated the project over to SvelteKit, which eventually became [my current personal portfolio](https://madr.io)

```
pnpm i
pnpm run dev
pnpm run build
```
